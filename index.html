1. 眼動校正

盯著可調直徑的圓球（定點或沿軌跡移動），程式即時估計視線並自動追加校正點，直到誤差落入球半徑內。附校正誤差指示條。

請先做這個
🖱️

2. 眼控滑鼠

視線移動游標，眨左眼＝左鍵、眨右眼＝右鍵。含懸停、點擊、右鍵選單與打靶練習，可驗證控制效果。

頁面內虛擬游標
🏎️

3. 眼控賽車

偽 3D 公路賽車：看左右控制車子，眨眼發射飛彈，炸掉前方的車輛、石頭與樹木。

眨眼開火
  1. 使用 Chrome / Edge，網址必須是 https:// 或 localhost（相機權限要求）。
  2. 臉部正對鏡頭、光線均勻（避免背光），螢幕全螢幕效果最好。
  3. 先到「眼動校正」完成校正（結果存在瀏覽器），再玩其他兩款。
  4. 沒有鏡頭想先試玩？在任一頁網址後加 ?mock：滑鼠＝視線，Z/X/空白＝左眼/右眼/雙眼眨。校正｜滑鼠｜賽車
