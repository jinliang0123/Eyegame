# 👁️ 眼動控制遊戲集錦

純前端（無需後端、無需安裝）的眼動控制網頁，使用網路攝影機 + [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker)（含虹膜關鍵點與眨眼 blendshape）。影像只在瀏覽器本機處理。

| 頁面 | 說明 |
|---|---|
| `index.html` | 首頁／校正狀態 |
| `calibrate.html` | **眼動校正**：可調直徑圓球，定點模式（自動追加校正點、驗證誤差）或軌跡模式（圓球沿路徑移動，視線跟隨）；頂部有**校正誤差指示條**（白線＝球半徑），誤差進入球半徑內即完成並存檔 |
| `mouse.html` | **眼控滑鼠**：視線移動虛擬游標，眨左眼＝左鍵、眨右眼＝右鍵 |
| `race.html` | **眼控賽車**：偽 3D 公路，看左右控制車子，眨眼發射飛彈炸掉車輛／石頭／樹木 |

## 執行
相機需要 HTTPS 或 localhost：

```bash
python3 -m http.server 8000   # 然後開啟 http://localhost:8000
```
建議使用 Chrome / Edge。首次載入需連網下載 MediaPipe 模型（jsDelivr + Google Storage CDN）。

**沒有鏡頭也能試**：任一頁網址加 `?mock`——滑鼠＝視線，`Z`/`X`/空白＝左眼/右眼/雙眼眨。

## 原理
- **特徵**：兩眼虹膜相對眼角/眼瞼的比例（水平/垂直）＋頭部偏轉/俯仰（由臉部變換矩陣）＋臉部位置與大小。
- **映射**：嶺迴歸（樣本夠多時加入二次項）把特徵對應到螢幕座標，One-Euro 濾波降低抖動，眨眼期間凍結視線。
- **眨眼**：用 `eyeBlinkLeft/Right` 分數＋遲滯；單眼閉合超過約 140 ms 且另一眼睜開才算「眨單眼」，自然眨眼（雙眼同時、很短）會被忽略。若左右相反，在校正/滑鼠頁勾選「左右眼對調」。
- **校正收斂**：定點模式用「加入此點前的模型」去預測新點得到真實驗證誤差，最近 8 點平均 ≤ 球半徑才通過；軌跡模式用近 5 秒滾動平均（含 130 ms 視線延遲補償）。

## 限制
- 瀏覽器無法控制作業系統的真實滑鼠；「眼控滑鼠」是頁面內的虛擬游標（可操作該頁的按鈕等元素）。
- 一般網路攝影機的眼動精度有限；球半徑設太小（< ~30 px）可能無法收斂，可加大直徑。校正後盡量不要大幅移動頭部。
